# Security

SuperEditr reads the text you select in other apps and can hold API keys, so security reports matter.

Report a vulnerability privately through GitHub: on this repository's **Security** tab, choose
**Report a vulnerability**. Don't open a public issue. Include what an attacker could do, the steps
to reproduce it, and the SuperEditr and macOS versions.

You'll get a reply within a week. Fixes ship in the next official build, and we credit reporters in
the release notes unless you'd rather we didn't.

Only the newest official build gets security fixes.
